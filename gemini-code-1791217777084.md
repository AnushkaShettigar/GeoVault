# Full-Stack Integration Blueprint: Bhu-Aadhaar DPI (SIH26014)
**Context:** We are connecting a React frontend (generated via Stitch) with a Python backend using the Model Context Protocol (MCP). The goal is to fetch spatial land records from the backend and render them on an interactive GIS map.

## 1. Tech Stack Requirements
- **Frontend:** React, Tailwind CSS, `react-leaflet`, `leaflet`.
- **Backend:** Python, FastAPI.
- **Data Exchange Format:** Strictly GeoJSON (`FeatureCollection`).

## 2. Backend Instructions (Python / FastAPI)
Write a Python FastAPI endpoint that acts as the data provider for the GIS map. 
- Create an endpoint `GET /api/v1/parcels`.
- The endpoint must return a valid GeoJSON `FeatureCollection`. 
- Each `Feature` in the GeoJSON must represent a land parcel.
- Include properties in the GeoJSON: `ulpin`, `owner_name` (masked like 'R**** S****'), `area`, and `status`.
- *MCP Tool Requirement:* Expose this database querying function as an MCP Tool so the AI can dynamically retrieve and verify land geometries.

## 3. Frontend Instructions (React + Leaflet)
Create a React component named `BhuExplorerMap.jsx`.
- Use `MapContainer`, `TileLayer`, and `GeoJSON` from the `react-leaflet` library.
- **Base Map:** Set the `TileLayer` url to a standard open-source tile provider (e.g., OpenStreetMap or ISRO Bhuvan if WMS is configured). Set default center coordinates to [28.4595, 77.0266] (Haryana region) and zoom level to 15.
- **Data Fetching:** Use React `useEffect` to fetch the GeoJSON data from the Python backend (`http://localhost:8000/api/v1/parcels`). Store it in a state variable `const [parcels, setParcels] = useState(null)`.
- **Rendering Polygons:** Pass the `parcels` state to the `<GeoJSON data={parcels} />` component.
- **Interactivity (`onEachFeature`):** Write a function that binds a popup to each polygon. When a user clicks a land parcel on the map, a Leaflet popup should appear displaying the ULPIN, the masked owner name, and the area.

## 4. Styling & State Logic
- Ensure the map takes up the full height and width of its parent container (`className="h-full w-full z-0"`).
- Style the polygons dynamically: If `feature.properties.status === 'disputed'`, set the polygon fill color to `#DC2626` (Crimson Red). Otherwise, set it to `#047857` (Forest Green).

## Expected Output Sequence:
1. Generate the Python FastAPI `main.py` code to serve the GeoJSON.
2. Generate the React `BhuExplorerMap.jsx` component code.
3. Provide instructions on how to mount the Map component inside the main Stitch UI dashboard.
